# Этап 1. Минимальный прототип с конфигурацией

Вариант №25, практическая работа №2 по дисциплине «Конфигурационное управление».

## Общее описание

`depviz` — будущий инструмент визуализации графа зависимостей для менеджера пакетов Ubuntu (apt).
На этом этапе реализовано минимальное CLI-приложение на Java: оно принимает параметры из опций
командной строки, проверяет их и выводит в формате ключ-значение. Зависимости пока не загружаются.
Внешних библиотек нет, нужен только JDK 17 или новее.

## Параметры

| Опция | Коротко | Значение | Обязательна | Параметр из задания |
|---|---|---|---|---|
| `--package` | `-p` | имя пакета | да | Имя анализируемого пакета |
| `--repository` | `-r` | URL или путь к файлу | да | URL-адрес репозитория или путь к файлу тестового репозитория |
| `--test-mode` | `-t` | флаг | нет, `false` | Режим работы с тестовым репозиторием |
| `--output` | `-o` | имя файла `.svg` | нет, `graph.svg` | Имя сгенерированного файла с изображением графа |
| `--ascii-tree` | `-a` | флаг | нет, `false` | Режим вывода зависимостей в формате ASCII-дерева |
| `--help` | `-h` | флаг | нет | Показать справку |

Значение можно указать через пробел (`-p curl`) или через `=` (`--package=curl`).
Флаг можно указать без значения (`-t`) или явно (`--test-mode=false`).

## Проверки и обработка ошибок

При ошибке приложение сообщает сразу обо всех найденных проблемах в поток ошибок, печатает строку
использования и завершается с кодом `2`. При успешном запуске код завершения `0`.

| Параметр | Что считается ошибкой |
|---|---|
| Все опции | неизвестная опция, лишний аргумент, нет значения, повтор опции |
| `--package` | не задан или пуст; не соответствует формату имени пакета Ubuntu; в тестовом режиме содержит что-то, кроме больших латинских букв |
| `--repository` | не задан или пуст; без тестового режима — не URL `http(s)`; в тестовом режиме — файл не найден, это каталог или нет доступа на чтение |
| `--test-mode` | значение не `true` и не `false` |
| `--output` | имя не вида `<имя>.svg`; совпадает с существующим каталогом; каталог для файла не существует |
| `--ascii-tree` | значение не `true` и не `false` |

## Структура проекта

| Путь | Назначение |
|---|---|
| `src/depviz/Main.java` | точка входа, вывод результата и ошибок |
| `src/depviz/Option.java` | описание опций командной строки |
| `src/depviz/ArgumentParser.java` | разбор аргументов на пары опция-значение |
| `src/depviz/ConfigValidator.java` | проверка значений опций |
| `src/depviz/Config.java` | проверенные параметры и их вывод в формате ключ-значение |
| `src/depviz/ConfigException.java` | исключение со списком ошибок |
| `tests/depviz/MainTest.java` | тесты |
| `tests/demo_errors.sh` | демонстрация обработки ошибок |
| `tests/data/test_repo.txt` | пример файла тестового репозитория |

## Сборка и запуск тестов

```bash
make build
```

```bash
make test
```

```bash
make demo
```

```bash
make clean
```

Запуск приложения (`run.sh` сам собирает проект):

```bash
./run.sh -p curl -r http://archive.ubuntu.com/ubuntu
```

## Примеры использования

Обычный режим:

```text
$ ./run.sh -p curl -r http://archive.ubuntu.com/ubuntu
package=curl
repository=http://archive.ubuntu.com/ubuntu
test_mode=false
output=graph.svg
ascii_tree=false
```

Тестовый режим, все параметры заданы:

```text
$ ./run.sh -p A -r tests/data/test_repo.txt -t -o out.svg -a
package=A
repository=tests/data/test_repo.txt
test_mode=true
output=out.svg
ascii_tree=true
```

Ошибка в одном параметре:

```text
$ ./run.sh -p A -r tests/data/missing.txt -t
Ошибка: Файл тестового репозитория не найден: 'tests/data/missing.txt'
Использование: depviz -p <пакет> -r <репозиторий> [-t] [-o <файл.svg>] [-a]
```

Ошибки в нескольких параметрах:

```text
$ ./run.sh -p 'Bad!' -r bad -o bad.png -a=bad
Ошибка: Опция --ascii-tree принимает только true или false, получено: 'bad'
Ошибка: Недопустимое имя пакета Ubuntu: 'Bad!'
Ошибка: Репозиторий должен быть URL-адресом http(s), получено: 'bad'. Для файла тестового репозитория укажите --test-mode
Ошибка: Имя файла графа должно иметь вид <имя>.svg, получено: 'bad.png'
Использование: depviz -p <пакет> -r <репозиторий> [-t] [-o <файл.svg>] [-a]
```

Все случаи ошибок для каждого параметра показывает `make demo`.
